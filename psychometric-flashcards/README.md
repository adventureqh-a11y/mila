# מילה

אפליקציית כרטיסיות בעברית ובאנגלית, ללא חשבון או שרת נתונים. כוללת 24 מילים ראשונות, עריכת מילים, חזרות מתוזמנות, סטטיסטיקות וגיבוי. כל הנתונים נשמרים במכשיר.

## שימוש באייפון

1. העלו את תוכן התיקייה לאחסון אתר סטטי עם HTTPS. אפשר להשתמש בחינם ב־GitHub Pages: צרו repository, העלו את הקבצים (כולל תיקיית icons), ובחרו Settings → Pages → Deploy from a branch → main → /(root) → Save.
2. פתחו את כתובת האתר שמופיעה ב־Pages באמצעות Safari באייפון. בחרו שיתוף → הוסף למסך הבית → הוסף.
3. פתחו ממסך הבית עם אינטרנט והמתינו להודעה ״מוכן לשימוש ללא אינטרנט״. מעכשיו אפשר ללמוד גם במצב טיסה.

מומלץ להתקין לפני שמתחילים ללמוד. אם צריך להעביר התקדמות בין מכשירים או בין הדפדפן לאפליקציה, השתמשו בהתקדמות → ייצוא גיבוי ובמכשיר היעד → שחזור גיבוי. אין סנכרון אוטומטי. ניקוי נתוני האתר עשוי למחוק את ההתקדמות.

## הפעלה מקומית אופציונלית

התקינו Node.js LTS. פתחו מסוף בתיקייה והריצו `npm start`, ואז פתחו `http://localhost:4173`. אין צורך ב־npm install. אפשר גם להריץ ב־Windows את `./start.ps1` אם VS Code מותקן במיקום הרגיל. פתיחת קובץ HTML בלחיצה כפולה לא מספיקה להתקנה או לעבודה במצב לא מקוון.

בדיקות אוטומטיות: `npm test`.

## התנהגות החזרות

״ידעתי״ מתזמן חזרה לעוד 1, 3, 7, 14, 30, ואז 60 ימים. ״עדיין לא״ מאפס את הרצף ומתזמן חזרה בעוד דקה. לאחר שלוש תשובות רצופות של ״ידעתי״ המילה נחשבת מבוססת. מילים מבוססות ממשיכות להופיע בחזרות. עריכת מילה שומרת את התזמון שלה. הסטטיסטיקות מונות חזרות, כולל חזרות על מילים שנמחקו. החפיסות ההתחלתיות הן דוגמאות ללימוד, ואינן מאגר רשמי של הבחינה.

בעת עדכון קובצי האפליקציה יש להגדיל את גרסת CACHE בקובץ sw.js. לאחר העלאה, פתחו עם אינטרנט וסגרו את כל חלונות האפליקציה כדי לאפשר לעדכון להיכנס לתוקף.
